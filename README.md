# 米兰设计周活动页原型

主题：东方新语，潮启未来。

## 本地打开

1. 将压缩包保存到电脑桌面。
2. 右键压缩包，选择“全部解压缩”。
3. 双击 index.html，使用 Chrome、Edge 等浏览器打开。

页面的样式和交互脚本都包含在 index.html 中，无需安装依赖，也无需启动服务器。

## GitHub Pages 发布

将本目录中的 index.html、.nojekyll 和 README.md 上传至公开仓库的 main 分支。
进入仓库 Settings → Pages，将 Source 设置为 Deploy from a branch，选择 main 分支和 / (root) 目录，保存。发布完成后以 GitHub 提供的地址为准。

## 演示范围

包括四个栏目、企业命题、报名与咨询入口、预约管理演示、分享海报，以及四栏目底部赛事咨询。
咨询预约只保存在当前浏览器会话中，不会实际提交到业务系统。二维码、往届真实素材和未确认规则已使用明确占位。
